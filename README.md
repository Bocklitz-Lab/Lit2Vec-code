# Lit2Vec: Open Chemistry Corpus with Paragraph Embeddings

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.xxxxxx.svg)](https://doi.org/10.5281/zenodo.xxxxxx)
[![Hugging Face](https://img.shields.io/badge/dataset-huggingface-datasets-orange)](https://huggingface.co/datasets/YOUR_ORG/lit2vec)
[![License](https://img.shields.io/badge/license-CC--BY--4.0-brightgreen)](LICENSE)
[![CI](https://github.com/YOUR_ORG/lit2vec/actions/workflows/ci.yml/badge.svg)](https://github.com/YOUR_ORG/lit2vec/actions/workflows/ci.yml)

**Lit2Vec** is a fully open, license-audited corpus of over 580,000 chemistry research articles, each processed into paragraph-level embeddings for use in retrieval-augmented generation, classification, summarization, and knowledge discovery.

- 📚 **Corpus size**: 580k CC-licensed full-text chemistry papers
- 🧪 **Fields**: 18 subfields (e.g., catalysis, synthesis, materials)
- 🧩 **Embeddings**: 1024-dim vectors (E5 base) at paragraph level
- ⚖️ **Legality**: All text sources allow redistribution & derivative use
- 🔁 **Reproducibility**: End-to-end pipeline, checksums, and schema
- 🔍 **Usage**: Chunked FAISS index, TL;DR summaries, subfield classifier

> 💡 This repository accompanies our *Scientific Data* manuscript:  
> **“Lit2Vec: a CC-licensed corpus of chemistry literature with paragraph embeddings for retrieval-augmented research”**  
> → [Read the paper](https://doi.org/10.1038/s41597-20XX-XXX)

## 🔧 Quickstart

### Install

```bash
git clone https://github.com/YOUR_ORG/lit2vec.git
cd lit2vec
conda env create -f environment.yml
conda activate lit2vec
````

### Build the dataset

```bash
make all
# or step-by-step:
make ingest
make normalize
make chunk
make embed
make validate
make package
```

### Run pipeline profiles

```bash
make repro
make prod
```

The current reproducibility pipeline is preserved as-is. The production profile
uses the same stage code but a separate config and output location, so future
production-only modules can be added without forking the existing stage logic.

### Download the release

```bash
wget https://zenodo.org/record/XXXXX/files/lit2vec-v1.0.0.tar.gz
tar -xvf lit2vec-v1.0.0.tar.gz
```

## 🧬 What’s in the Dataset?

| Field                      | Description                                |
| -------------------------- | ------------------------------------------ |
| `id`                       | Persistent identifier (DOI, UUID, etc.)    |
| `title`, `authors`, `year` | Metadata                                   |
| `license_final`            | Final resolved license                     |
| `abstract`                 | Normalized abstract                        |
| `paragraphs`               | Full-text, markdown-formatted              |
| `subfield`                 | Pseudo-labeled chemistry domain            |
| `summary`                  | TL;DR generated by DistilBART (CC-BY only) |
| `embeddings`               | 1024-dim float32 vectors (E5)              |

See [`schema/record.schema.json`](schema/record.schema.json) for a full field list.

## 📊 How to Use

### Search over paragraphs with FAISS

```python
from faiss import read_index
import numpy as np

index = read_index("embeddings/faiss_index.bin")
query_vec = np.load("query_embedding.npy")  # 1024-dim E5 vector
scores, ids = index.search(query_vec, k=10)
```

### Load from Hugging Face Datasets

```python
from datasets import load_dataset
ds = load_dataset("YOUR_ORG/lit2vec", split="train")
print(ds[0]["paragraphs"][:3])
```

## Simplified for Reproducibility

The released code is a cleaned, modular version of our production pipeline.
It mirrors the full logic (e.g., license filtering, chunking, embedding) using a small demo subset (5 papers),
and is designed for transparency, reproducibility, and ease of inspection.

The full-scale version used MongoDB filtering and parallel embedding; logic is identical.

To keep the reproducibility path stable while making room for production, this
repo now includes a shared runner at [`pipelines/run_pipeline.py`](pipelines/run_pipeline.py)
plus separate configs under [`configs/repro/`](configs/repro/) and
[`configs/production/`](configs/production/). Production-only stages can be
added later by inserting their module paths into `PIPELINE.stages` in the
production config.

## 🤖 Models

This project provides two pretrained models to enrich the Lit2Vec dataset:

### 🔬 1. Subfield Classifier — [`lit2vec-subfield-classifier`](https://github.com/your-org/lit2vec-models/tree/main/subfield-classifier)
A multi-layer perceptron (MLP) trained on abstract embeddings to predict 18 chemistry subfields.  
Used to annotate each document in the corpus with a predicted subfield and confidence score.

- Input: 768-dim E5-base-v2 embeddings of abstracts
- Output: One of 18 chemistry domains (e.g., Organic, Physical, Biochemistry)
- Accuracy: ~92.7% on a GPT-4o-labeled CC-BY validation set

👉 [View code and training configs](https://github.com/Bocklitz-Lab/lit2vec-subfield-classifier)  
📦 [Pretrained model on Hugging Face](https://huggingface.co/Bocklitz-Lab/lit2vec-subfield-classifier)

---

### ✍️ 2. TL;DR Summarizer — [`lit2vec-tldr-bart`](https://github.com/your-org/lit2vec-models/tree/main/tldr-bart)
A fine-tuned DistilBART model that generates TL;DR-style summaries for scientific abstracts.  
Summaries are included in the dataset under the `summary_tldr` field.

- Base model: `sshleifer/distilbart-cnn-12-6`
- Training: 43k CC-BY abstracts with GPT-4o-generated summaries
- BLEURT: 0.318 ± 0.05

👉 [View code and configs](https://github.com/Bocklitz-Lab/lit2vec-tldr-bart)  
📦 [Pretrained model on Hugging Face](https://huggingface.co/Bocklitz-Lab/lit2vec-tldr-bart)
